Adversary ICU is an analyst-facing publication and research archive covering malware reports, campaign notes, telemetry analysis, and security tooling. The emphasis is on reproducible lab observations, clear technical evidence, and practical defensive visibility, operated under [Pine and Packets LLC](https://pineandpackets.com/).
